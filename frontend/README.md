# 大符灯板调光台

在工程根目录运行 `python -m http.server 8770 --bind 127.0.0.1 --directory frontend`，用桌面版 Chrome 或 Edge 打开 [调光台](http://127.0.0.1:8770)。点「离线演示」即可试用滑块、档位按钮及趋势图。

真机调光需要刷入根目录的 `led231_control.uf2`。按原有方式进入 UF2 bootloader，并将新文件复制到对应的 UF2 盘。板卡重启后进入网页，点「连接串口」，选择灯板的 USB CDC 端口（VID/PID 为 `239A:80DA`）。旧版 `led231_blue.uf2` 是固定蓝光固件。重新构建调光固件使用 `python build.py`。

亮度用蓝通道值 `B/255` 换算为等效占空比，现阶段限定 `B=0…8`，每档约 0.39%。灯链 DIN 的位时序保持原配置。页面显示固件下发结果及参数，灯板是否实际点亮需观察实物。现有固件未接入灯板电压、电流和温度传感器，供电仍需独立限流。

固件上电先发熄灯帧。控制板保持供电时，关闭串口或停止心跳会触发熄灯。若拔掉 USB 会同时让控制板掉电，而灯板仍由外部供电，灯珠可能保持最后的亮度。请先点「立即熄灯」并等待回报，或切断灯板独立电源。

## 串口协议

使用 115200 波特率并置 DTR，命令以换行结束。每条命令返回一行带 `protocol: "LED231/1"` 的 JSON。状态的 `blue: -1` 表示帧发送结果未知。

- `GET` 读取状态。
- `SET 0` 至 `SET 8` 更新亮度。超范围指令返回 `LIMIT`。
- `KEEP` 维持当前亮度。超时后的熄灯状态需要重新发送 `SET` 才能恢复亮度。
- `?` 保留旧版简短诊断命令，可以不加换行。
